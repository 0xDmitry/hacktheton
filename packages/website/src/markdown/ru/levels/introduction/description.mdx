# Перед началом игры:

1. ## Установите и подключите кошелек

   Если у вас еще нет TON кошелька, установите его (например, [Tonkeeper](https://tonkeeper.com/)) и подключите к сайту. Не забудьте [переключиться на Testnet](https://answers.ton.org/question/1561527682871595008/how-do-you-change-ton-keeper-to-testnet).
   Вам также понадобится тестовый TON. Для его получения перейдите в бот [@testgiver_ton_bot](https://t.me/testgiver_ton_bot).

2. ## Получите инстанс уровня

   Нажмите кнопку "ПОЛУЧИТЬ НОВЫЙ ИНСТАНС" внизу страницы. Tonkeeper попросит у вас авторизовать транзакцию. Обратите внимание: развертывание нового контракта в блокчейне может занять некоторое время. Поэтому, пожалуйста, проявите терпение при запросе новых инстансов уровня!

3. ## Изучите информацию в консоли

   Вы должны увидеть таблицу с полезными утилитами, которые доступны вам в консоли. Вы можете повторно вызвать данную таблицу, набрав команду `help()`.

# Для прохождения уровня:

1. ## Изучите контракт

   Вы можете ознакомиться с ABI контракта через консоль, используя переменную `contract`.

2. ## Взаимодействуйте с контрактом

   Посмотрите информацию об уровне, используя метод `await contract.getInfo()`. Затем следуйте полученным подсказкам.

   Чтобы отправить сообщение контракту, введите:

   `await contract.send(player, {value: toNano(0.05)}, {$$type: "MessageName", ...params})`

   Когда вы будете уверены, что завершили уровень, нажмите кнопку "ПРОВЕРИТЬ РЕШЕНИЕ" внизу страницы.
   Так вы отправите сообщение менеджеру игры, который проверит, прошли ли вы уровень.
